# MSc Thesis - Gender Citation Imbalance in Computer Science

Code and analysis for the Master's thesis:

**Quantifying Gender Citation Imbalance in Computer Science Across Citation-Derived Network Representations**  
Eindhoven University of Technology (TU/e), 2026.

## Overview

This project investigates gender citation imbalance in Computer Science using an
Observed/Expected (O/E) framework under multiple definitions of citation opportunity
and scholarly comparability.

The analysis compares:

- direct citation baselines,
- taxonomy-based topical relevance,
- bibliographic-coupling neighborhoods,
- co-citation neighborhoods,
- generalized linear models (GLMs),
- citation-lag and long-memory analyses,
- randomized reference-drawing baselines,
- network-conditioned citation randomization.

Results are evaluated for two main citation slices:

- **All → CS** - citations to Computer Science papers from the complete observed corpus,
- **CS → CS** - citations where both the citing and cited papers are classified as Computer Science.

Paper-level gender categories are constructed from inferred first- and last-author gender:

- `MM` - male first author, male last author,
- `MW` - male first author, female last author,
- `WM` - female first author, male last author,
- `WW` - female first author, female last author.

Papers with an unknown first- or last-author gender assignment are retained where
required for coverage diagnostics but excluded from the main known-gender O/E analyses.

## Analysis Pipeline

The notebooks are numbered according to the analysis workflow. Later notebooks
generally depend on datasets or outputs generated by earlier stages.

| Notebook | Description |
|---|---|
| `00_data_loading_preprocessing.ipynb` | Loads and cleans the raw bibliographic dataset, extracts author information and OpenAlex identifiers, performs name-based gender inference, constructs the analytical paper table and citation edges, and applies the main preprocessing filters. |
| `01_final_eda.ipynb` | Performs the main exploratory data analysis, including corpus composition, metadata coverage, publication trends, authorship, gender composition, venues, taxonomy, and reference-list characteristics. |
| `02_direct_citation_network.ipynb` | Constructs the final directed citation representation and prepares the All→CS and CS→CS citation slices used throughout the analysis. |
| `03_cocitation_network.ipynb` | Constructs the sparse weighted co-citation network, where papers are connected according to shared citing papers. |
| `04_bibliographic_coupling_network.ipynb` | Constructs the sparse weighted bibliographic-coupling network, where papers are connected according to shared references. |
| `05_network_eda.ipynb` | Examines citation-derived network coverage, retained edge weights, degree, strength, feature distributions, and gender-specific network diagnostics. |
| `06_baseline_d0_global_paper_share.ipynb` | Computes D0, the global known-gender Computer Science paper-share baseline. |
| `07_baseline_d1_decade.ipynb` | Computes D1, conditioning expected citation shares on publication decade. |
| `08_baseline_d2_subfield_topic.ipynb` | Computes D2 using decade × subfield conditioning and evaluates additional topic-level sensitivity specifications. |
| `09_baseline_d3_venue.ipynb` | Computes D3 using publication decade and venue-rank strata. |
| `10_baseline_r1_taxonomy_relevance.ipynb` | Evaluates topical-relevance specifications using OpenAlex taxonomy relationships and taxonomy-weighted citation edges. |
| `11_baseline_n1_bibliographic_coupling.ipynb` | Computes N1, a local expected-citation baseline based on weighted bibliographic-coupling neighborhoods. |
| `12_baseline_n2_cocitation.ipynb` | Computes N2, a local expected-citation baseline based on weighted co-citation neighborhoods. |
| `13_unified_expected_observed_framework.ipynb` | Standardizes baseline outputs and combines them into a common Observed/Expected comparison framework. |
| `14_baseline_m1_combined_glm.ipynb` | Fits the structural M1 expected-citation generalized linear model. |
| `15_baseline_m2_combined_structural_network_glm.ipynb` | Constructs the combined structural and citation-network GLM specification used in the network-augmented model sequence. |
| `16_glm_models_diagnostics_validation.ipynb` | Fits and compares the final M1-M5 GLM specifications, evaluates model diagnostics, computes gender-level O/E ratios, and performs held-out validation. |
| `17_long_memory_citation_flow.ipynb` | Analyzes gender citation patterns across citation-lag groups and short-, middle-, and long-memory citation relationships. |
| `18_randomized_drawing_baseline_weighted.ipynb` | Implements randomized reference-drawing baselines under alternative temporal eligibility rules and uniform or prior-citation-weighted sampling. |
| `19_network_conditioned_edge_randomization.ipynb` | Performs citation-edge randomization within bibliographic-coupling and co-citation replacement neighborhoods. |
| `20_bib_coupling_edge_randomization_prior_weighted.ipynb` | Extends bibliographic-coupling randomization by incorporating historical prior-citation visibility into replacement probabilities. |
| `22_randomized_robustness_figures.ipynb` | Produces summary figures and coverage diagnostics for the randomized robustness specifications. |
| `23_cross_baseline_robustness.ipynb` | Combines the principal baseline specifications and evaluates cross-baseline directional stability and variation in O/E magnitude. |
| `24_visual_polish_figures.ipynb` | Generates the final publication-quality comparison figures used in the thesis. |

Corresponding result directories are stored under `outputs/` using the same
numbering wherever applicable.

## Reproducing the Analysis

The analysis is organized as a sequential notebook pipeline.

A simplified workflow is:

```text
Raw bibliographic data
        ↓
Data loading and preprocessing
        ↓
Direct citation network
        ↓
Co-citation and bibliographic-coupling networks
        ↓
Exploratory and network diagnostics
        ↓
Direct and topical O/E baselines
        ↓
Network-neighborhood baselines
        ↓
GLM expected-citation models
        ↓
Citation-lag analysis
        ↓
Randomized robustness checks
        ↓
Cross-baseline comparison
        ↓
Final thesis figures
```

For a complete reconstruction of the workflow, run the notebooks in numerical
order while retaining the intermediate datasets generated by previous stages.

Several steps operate on millions of publications or citation edges. Network
construction, randomized analyses, and GLM fitting can therefore require
substantial memory and execution time.

## Methodological Notes

Gender is inferred from author names using `nomquamgender`. These assignments are
an analytical operationalization and should not be interpreted as observed
self-identified gender.

Observed/Expected ratios compare observed citation reception with expectations
defined under a particular baseline. Different baselines encode different
definitions of citation opportunity and scholarly comparability; they are therefore
not expected to produce identical effect magnitudes.

The analyses are descriptive rather than causal.

Co-citation-based analyses are retrospective and future-informed because
co-citation relationships are constructed using subsequent citing activity.

The thesis document should be consulted for the complete methodological definitions,
limitations, interpretation of the results, and final reported findings.
